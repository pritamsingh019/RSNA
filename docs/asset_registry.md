## Required adoption record

For any future approved asset, record purpose, exact source URL, provider and version, retrieval date, license or usage terms, competition-rule compatibility, size, SHA-256, offline location, and approval evidence. State redistribution rights and reproducible access instructions.

Credentials, tokens, private keys, dataset images, and large weights never belong in this registry or Git. A URL alone is insufficient provenance for an unidentified file. Incomplete or conflicting terms block adoption until resolved.

External-asset review is separate from choosing a repository code license. Do not apply a code license to competition data or third-party weights.
